Windows

Open the downloaded certificate, choose Install Certificate → Current User → Place all certificates in the following store → Trusted Root Certification Authorities. Verify the name and SHA-256 fingerprint before confirming.

Removal: open certmgr.msc, locate this CA under Trusted Root Certification Authorities → Certificates, and delete only that entry.

macOS

Import the file into Keychain Access (login or System keychain), open the certificate entry, expand Trust, and set SSL to Always Trust.

Removal: locate this NetBridge CA in Keychain Access and delete it.

iOS / iPadOS

Download in Safari, install the profile under Settings → General → VPN & Device Management, then enable full trust under Settings → General → About → Certificate Trust Settings. Apple documentation.

Android

Install via Settings → Security & privacy → Encryption & credentials → Install a certificate → CA certificate. Note that Android user CAs do not apply to apps targeting modern network security configs without app modification. Android documentation.

Linux & Firefox

Debian/Ubuntu: copy as .crt into /usr/local/share/ca-certificates/ and run sudo update-ca-certificates. For Firefox, import under Settings → Privacy & Security → Certificates → View Certificates → Authorities. Mozilla documentation.
