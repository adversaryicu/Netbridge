Install and remove the certificate

Choose your platform. Menu names may vary by OS version. Restart the browser after changing trust.

Windows

Open the downloaded certificate, choose Install Certificate, and select Current User. Choose Place all certificates in the following store, then Trusted Root Certification Authorities. Verify the NetBridge name and fingerprint before accepting.

To remove it, open certmgr.msc, find this NetBridge CA under Trusted Root Certification Authorities → Certificates, and delete only that certificate.

macOS

Open the certificate in Keychain Access and add it to your login or System keychain. Open the imported NetBridge certificate, expand Trust, and explicitly trust it for SSL. You may need an administrator password.

To remove it, find this exact NetBridge CA in Keychain Access and delete it.

iPhone and iPad

Download the certificate in Safari and install the downloaded profile from Settings → General → VPN & Device Management. Then open Settings → General → About → Certificate Trust Settings and enable full trust for this NetBridge CA.

To remove it, delete the NetBridge profile under VPN & Device Management. Apple’s trust instructions.

Android

In Settings, find Security or Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate, then select the downloaded file. A device lock and a security confirmation may be required.

Many apps do not accept user-installed CAs, even when your browser trusts this one. To remove it, select this NetBridge CA in user credentials/trusted credentials and remove it. Google’s certificate instructions.

Linux and Firefox

For Debian/Ubuntu system trust, save the certificate with a .crt extension under /usr/local/share/ca-certificates/ and run sudo update-ca-certificates. To remove it, delete that specific file and run the command again. Other distributions use different trust tools.

If Firefox does not use your system trust, open Settings → Privacy & Security → Certificates → View Certificates → Authorities, import this CA, and allow it to identify websites. Remove the same CA from Authorities when finished. Mozilla’s CA guidance.

CA rotation replaces this identity. Remove the old certificate, install the new one, and repeat the trust check. Pinned apps, VPNs and app-specific trust rules can still prevent inspection.
